Yes. Looking at this version specifically as a **lead-generation website**, I would change quite a lot. The current design is already visually strong, but it is still somewhat **“presentation-first” rather than “conversion-first.”**

The most important question should be:

> **What does a visitor need to see to feel confident enough to contact you?**

And that leads to a different structure.

## 1. My biggest change: make the website about the customer's problem

Right now the flow is roughly:

**Hero → Services → Process → Prices → Symptoms → Coverage → CTA**

I'd change it to:

**Hero → “Can we help with your problem?” → What we diagnose → What you get → How it works → Coverage → Pricing → FAQ → Final CTA**

The key addition is a **diagnostic/problem selector**.

# 3. The "What can we diagnose?" block needs redesigning

This is probably the biggest weak point in the current design.

You currently have five small cards:

> OBD
> Live data
> Check Engine
> ABS
> Mobile diagnostic

They're visually nice, but they're **not very informative**.

And there's some conceptual overlap:

* "Diagnóstico computadorizado / OBD"
* "Códigos e dados em directo"
* "Luz do motor"
* "ABS e airbag"

These aren't really four different services. They're largely **capabilities of the diagnostic process**.

I'd turn this into something much more useful.

### Option A — visual diagnostic system

Something like:

```text
What can we diagnose?

        ┌───────────────┐
        │   VEHICLE     │
        │               │
        │      🚗       │
        └───────────────┘

  ENGINE       ABS / ESP
  AIRBAG       TRANSMISSION
  ELECTRONICS  LIVE DATA
```

Clicking a system opens the relevant explanation.

This would fit your brand **much better** because you're selling diagnostic expertise.

---

### Option B — customer problems

Personally, I like this even more for conversion:

## What can we help you with?

|                       |                          |
| --------------------- | ------------------------ |
| 🟠 Check Engine light | 🟠 ABS / ESP warning     |
| 🟠 Airbag warning     | 🟠 Loss of power         |
| 🟠 Strange behaviour  | 🟠 Intermittent fault    |
| 🟠 Buying a used car  | 🟠 Not sure what's wrong |

Then:

> **Not sure what the problem is?**
> Tell us your car model and what you're experiencing. We'll tell you whether a diagnostic can help.

**[ Describe my problem → ]**

That is much more **lead-oriented**.

# And one more thing: the language selector

From your screenshot, **PT ▼** is actually one of the things I'd change.

Don't make it look like a generic form `<select>`.

Use:

**PT · Português ▾**

When opened:

```text
┌────────────────────────┐
│ ✓  Português            │
│    English              │
│    Українська           │
└────────────────────────┘
```

On desktop, a compact dropdown.

On mobile, I'd use a proper bottom sheet/popover rather than a tiny native-looking selector.

And because your site supports **Portuguese, Ukrainian and English**, I'd use the language **name**, not only the country flag. Flags represent countries, not languages.

## The most important principle

Your current version says:

> **"Here is our service."**

The redesigned version should say:

> **"You have a problem with your car. Let's figure out whether we can help."**

That is the difference between a **nice website** and a **lead-generation website**.

And I think your instinct about the diagnostic tool is exactly right. It can become the central interaction of the entire site and give the visitor a reason to engage instead of simply scrolling through information.
